  requerimientos de la landing. No solo aplicar colores y fuentes,
  sino asegurar coherencia total entre UX/UI, contenido y
  dirección estética/emocional.

  1.2. DIAGNÓSTICO ACTUAL
  ────────────────────────

  ESTRUCTURA (UX/UI):
  ✔ Requerimientos funcionales definidos (v3.0)
  ✔ Secciones claras (Servicios, Tienda, Checkpoint)
  ✔ Stack técnico definido y sin deuda de arquitectura
  ✖ Falta alineación profunda con identidad de marca
  ✖ Falta uso estratégico de tipografía display (Jelek)

  BRANDING DETECTADO (del Brand Book):

  ✔ Personalidad: Urbana / Relajada / Empática
  ✔ Tipografías definidas (Manrope / Jelek / UT Breado Script)
  ✔ Paleta cromática definida (Verde Musetta / Crema / Lavanda)
  ✔ Tono narrativo fuerte — manifiesto claro
  ✔ Ilustraciones de marca: ciclista con café

     pero aún no transmite la experiencia emocional KOS.
     Un usuario que la visite debe sentir que llegó a su lugar,
     no que está leyendo un catálogo de servicios.

  ──────────────────────

  1.4. VALIDACIONES CON EL CLIENTE (hacer ANTES de diseñar)
  ────────────────────────────────────────────────────────────
  Validar SOLO estas 3 preguntas para evitar retrabajos:

  ① ¿El concepto "Punto de llegada" es el eje central de toda

  Si las 3 respuestas son SÍ → proceder al diseño sin más rondas.

  5.1. PALETA OFICIAL BRAND BOOK
  ──────────────────────────────
  Nombre           HEX        RGB             Uso principal
  ─────────────────────────────────────────────────────────────────
  Verde Musetta    #0e3e34    14, 62, 52      Base / Navbar / Footer / fondos oscuros
  Crema Cafe       #f9f5dd    249, 245, 221   Fondo principal / textos sobre verde
  Lavanda Sprint   #d2cbed    210, 203, 237   Sección servicios / acentos / ilustraciones

  Escala del Verde Musetta:
  80% → rgba(14,62,52,0.8)  → overlays sobre fotografía
  50% → rgba(14,62,52,0.5)  → hover suave, separadores
  30% → rgba(14,62,52,0.3)  → fondos alternativos sutiles

  REGLA: no agregar colores fuera de este sistema.

  5.2. TIPOGRAFÍA OFICIAL BRAND BOOK
  ────────────────────────────────────
  Rol            Familia             Peso        Uso específico
  ──────────────────────────────────────────────────────────────────
  PRINCIPAL      Manrope (sans)      Light/Regular/Bold  Body, H2, UI
  DISPLAY        Jelek Type          Regular     H1, títulos emocionales grandes
  SCRIPT         UT Breado Script    Regular     Slogans, taglines aspiracionales

  Jerarquía aplicada en la landing:
  H1 → Jelek Type | Títulos principales de sección
       Ejemplo: "El café que te ganaste." / "Tu punto de llegada."
  H2 → Manrope Bold | Subtítulos de bloque funcional
       Ejemplo: "Tu ritual de cierre después de entrenar."
  H3 → UT Breado Script | Frases de valor / aspiracionales
       Ejemplo: "Entrenar. Frenar. Café." / "Coffee club."
  Body → Manrope Regular | Descripciones, datos, listas
  Small → Manrope Light | Labels, badges, metadata

  Carga de fuentes:
  Manrope → Google Fonts (https://fonts.google.com/specimen/Manrope)
  Jelek Type → importar desde assets o licencia
  UT Breado Script → importar desde assets o licencia

  5.3. ILUSTRACIONES DE MARCA

15. CONVENCIONES Y REGLAS ESTRICTAS
────────────────────────────────────────────────────────────────

  REGLAS ABSOLUTAS
  ─────────────────
  ✗  NO agregar frameworks (React, Vue, etc.)
  ✗  NO agregar librerías JS externas
  ✗  NO usar !important salvo @media prefers-reduced-motion
  ✗  NO romper las clases .reveal-* (el observer las necesita)
  ✗  NO escribir CSS inline en el HTML
  ✗  NO duplicar estilos ya definidos en :root
  ✗  NO crear archivos CSS nuevos (todo en styles.css / animations.css)
  ✗  NO crear archivos JS nuevos (todo en main.js)
  ✗  NO colocar botón de compra en la sección Tienda
  ✗  NO mostrar precios en la Tienda
  ✗  NO usar lorem ipsum en ninguna versión del proyecto (NUEVO v4.0)
  ✗  NO usar microcopy genérico: "Ver más" / "Comprar" / "Saber más"

  ✓  BEM estricto: bloque__elemento--modificador
  ✓  Variables CSS: siempre las de :root (brand book)
  ✓  Imágenes: width + height + loading="lazy" + alt descriptivo
  ✓  Links externos: target="_blank" rel="noopener noreferrer"
  ✓  ARIA: aria-label en elementos interactivos sin texto visible
  ✓  WhatsApp: siempre la misma variable/constante de número
  ✓  Copy KOS: siempre revisar con el sistema de tono de Sección 6

  CONVENCIONES DE NAMING
  ───────────────────────
  IDs de sección:  #inicio | #manifiesto | #servicios | #tienda
                   #abastecimiento | #eventos | #contacto
  IDs únicos JS:   navbar | navMenu | navBurger
  Clases reveal:   .reveal | .reveal-left | .reveal-right | .reveal-up
  Clases estado:   .is-visible | .is-open | .navbar--scrolled
  Clases tienda:   .tienda__card | .tienda__tabs | .tienda__btn-wa
  Clases servicio: .servicio__card | .servicio__icon | .servicio__cta

  ORDEN DE EDICIÓN
  ─────────────────
  Para cualquier cambio:
  1. index.html (PROD)
  2. descargas/config.js
  3. descargas/main.js si el campo no estaba inyectado
